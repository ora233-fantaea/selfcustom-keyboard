# 开槽与布线设计说明（2026-11-23 重做）

## 一、为什么旧版开槽无效

旧版 73 处内轮廓（69 个 6×1.2mm 竖槽 + 4 条长槽）实测结果：

| 指标 | 旧版实测 |
|---|---|
| 竖槽长度 / 键距 | 6.0 / 19.05 mm = **31%，上下不贯通** |
| 开槽总面积 | 810 mm² = 板面的 **1.46%** |
| 长槽端头与相邻竖槽间距 | **1.90 mm**，共 5 处（栅格实测 1.80mm） |
| 定位板对应开槽 | **无** |

结论：板面仍是连续整板，没有形成任何隔离；4 条长槽两端各留 1.9mm 桥，反而形成
两端固支的悬空板条（自已会振），与"防共振"目标相反。加上 plate 与 PCB 通过
4×M3 + 75 个轴座刚性连接，PCB 单侧开槽改变不了组合体模态，净收益≈0。

## 二、新方案：行间贯通铣槽 + 布线门

在 4 排字母区（行 1~4）及其与底行的边界上，做 **4 条 2.0mm 宽贯通铣槽**：

| 边界 | Y 坐标 | 槽覆盖 X 范围 | 布线门数 |
|---|---|---|---|
| 行1\|行2 | 68.58 | 26.0 – 311.0 | 3 |
| 行2\|行3 | 87.62 | 26.0 – 311.0 | 4 |
| 行3\|行4 | 106.68 | 26.0 – 311.0 | 5 |
| 行4\|行5 | 125.73 | 26.0 – 311.0 | 4 |

- **槽宽 2.0mm**：进入常规 2mm 锣刀能力范围，不再需要 1.2mm 小径刀逐处编程。
- **槽端与相邻结构无 <2mm 窄颈**：段端点严格对齐布线门边界。
- **两侧保留边缘脊**（x<26 / x>311），作为纵向布线主干，并保证板料单一连通。
- **布线门（gateway）** 是槽上的 8mm 缺口，兼作跨越槽的走线通道；
  每个门的通过能力约 20 条/层。

## 三、为布线做的配套改动

### 1. 网络重新分配（必须）
75 个单键网络原本按行优先编号（K01..K08 一片），导致每片芯片的 8 路输入
来自完全不相邻的位置，走线必然长距离横穿。

改为：**按 X 坐标排序，每 8 个键一组**，每片 74HC165 服务一个纵向窄带
（如 U1 服务 cx 34.5–53.6 的所有行）。走线以纵向为主。

> 影响：固件的位移位映射随之改变。映射表见 `kbd_design.py` 的 `CHIP_INPUTS`。
> `gen_sch.py` 需同步更新后才能保持原理图与 PCB 一致。

### 2. 上拉电阻迁移
75 个 10k 上拉从"每个轴座下方"迁到"各自芯片正上方"（4×2 阵列）。
行间净空从 1.6mm 释放为完整 8.17mm，全部让给横向走线。

### 3. 删除的旧件
旧的 69 个竖槽、4 条长槽全部删除。

## 四、工具链

```bash
python gen_pcb.py         # 生成板框/封装/开槽（不需 KiCad）
python autoroute.py       # 双层栅格 A* 布线（0.2mm 栅格）
python verify_pcb.py      # 间距 + 连通性校验
python render_pcb.py kbd-esp32s3.kicad_pcb pcb_preview.png
```

`gen_pcb.py` 直接从 `kbd-esp32s3_v1_template.kicad_pcb` 复用封装几何，
因此不需要安装 KiCad 库，也不需要 `pcbnew`。

### 布线未完成的具体原因
`autoroute.py` 首轮跑出 **123/183 条成功、60 条失败**，且校验出 78 处间距违例
（过孔压到 IC 焊盘、过孔间距不足、个别走线相交）。根因是布线器**未做过孔间距检查**
（障碍只按 0.3mm 膨胀，而过孔需要 0.5mm），以及 CLK/SH_LD 横向主干被底部密集区挡住。

修复方向（按优先级）：
1. `router.astar` 换层时检查 5×5 窗口（过孔半径 0.3 + 间距 0.2）。
2. CLK/SH_LD 改走芯片带下方（y≈162）的独立横向通道。
3. 底部带为 8 个上拉/芯片预留更大的横向让位，或改用 0603 双联排阻。

布线尝试保存为 `kbd-esp32s3_routed_wip.kicad_pcb`，**不可直接投产**。
`kbd-esp32s3.kicad_pcb` 是已通过间距校验的未布线版本。
